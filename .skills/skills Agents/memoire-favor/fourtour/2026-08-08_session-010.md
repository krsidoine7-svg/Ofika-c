## Corrections Techniques
- [BUG-RLS] Les politiques RLS sur `admin_audit_logs` bloquaient les insertions car elles lisaient `auth.jwt() ->> 'role'` (racine du JWT) au lieu de `auth.jwt() -> 'app_metadata' ->> 'role'`. Le trigger `sync_user_role_to_jwt` stocke le rôle dans `raw_app_meta_data`, donc le chemin correct dans le JWT est `app_metadata.role`.
  → Solution : Migration `20260808_fix_admin_jwt_rls.sql` exécutée — corrige toutes les politiques RLS admin (audit_logs, announcements, system_config, cards, orders, users, analytics_events, profiles).
- [BUG-FETCH] Les utilisateurs n'apparaissaient pas dans `/dashboard/admin/users` à cause des RLS trop restrictives.
  → Solution : Création de `app/dashboard/admin/users/actions.ts` — Server Action utilisant `createAdminClient` (Service Role) pour contourner les RLS et récupérer tous les utilisateurs.
- [BUG-404] `DELETE /api/admin/users` retournait 404 + `Unexpected token '<'` pendant la compilation initiale de Next.js. Comportement transitoire, pas un bug persistant.
