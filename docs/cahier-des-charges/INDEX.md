## 🛠️ Protocole d'Exécution avec Antigravity

Pour exécuter une version :
1. Sélectionner le fichier de spécification correspondant (ex: `V1-identite-visuelle.md`).
2. Suivre les étapes dans l'ordre (Étape 1 ➔ Étape 2 ➔ Étape 3 ➔ Étape 4).
3. Vérifier et valider chaque critère de test fonctionnel avant de passer à l'étape suivante.
