⏱️  TEMPS TOTAL: 20 minutes

1. INSTALLATION (2 min)
   npm install emoji-picker-react web-push

2. CLÉS VAPID (1 min)
   npx web-push generate-vapid-keys
   → Copier dans .env.local

3. MIGRATION SQL (3 min)
   Copier database/migrations/001_features_setup.sql
   → Supabase SQL Editor → Run

4. SERVICE WORKER (2 min)
   Copier docs/templates/sw-template.js
   → public/sw.js

5. TESTER (5 min)
   npm run dev
   → http://localhost:3000/example-integration

6. DÉPLOYER (7 min)
   npx supabase functions deploy send-push-notifications
   vercel --prod
