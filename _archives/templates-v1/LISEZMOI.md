# Anciens templates de page publique (v1)

Archivés le 08/11/2026, remplacés par les 8 nouveaux templates de
`components/features/profiles/templates/` (voir `lib/templates/registry.ts`).

Les profils qui utilisaient ces designs basculent automatiquement vers le
nouveau template le plus proche (`LEGACY_DESIGN_MAP` dans le registre).

Ce dossier est ignoré par TypeScript (`tsconfig.json` → `exclude`).
Il peut être supprimé une fois la bascule validée en production.
